## Step 1 — SERP research

Live web search, not a rendered browser SERP. Three queries run because the first two surfaced single-test "grader" tools (Easy Grader / EZ Grader), not the weighted-category gradebook tool this site's `/gradebook-calculator/` actually is:

- `online gradebook calculator` → mostly Easy Grader / EZ Grader single-test tools (calculator.net, ezgrader.us, gradecalculator.com, rapidtables, quickgra.de) — not a close intent match to this site's tool.
- `"gradebook calculator" online free teachers` → same single-test grader cluster (easygraderhub.com, easy-grader.net, gradercalculatorpro.com).
- `gradebook calculator weighted categories homework quiz midterm final` → correct intent match. Surfaced: miniwebtool.com, best-calculators.com, easygraderhub.com/grade/syllabus-grade-calculator/, **gradebookcalculator.com/weighted-grade-calculator/**, gradecalculatortools.com/weighted-grade-calculator/, **cumgpacalculator.com/gradebook-calculator/**, solvebility.com.

This confirms the site's own tool (weighted syllabus categories: homework/quiz/midterm/final → one overall course grade) matches the "weighted grade calculator" sub-intent, not the single-test "easy grader" sub-intent already covered by the `easy-grader-explainer` and `quick-grader-method` posts.
